Gauss-Newton optimization#

Consider a least squares problem on the form:

\[\min_{\mathbf{p}} = \frac{1}{2} \left(\| \mathbf{r}(\mathbf{p}) \|^2\right)\]

where \(\mathbf{r}\) is a residual function (\(\mathbb{R}^{n_p} \rightarrow \mathbb{R}^{n_r}\)) depending on the parameters \(\mathbf{p} \in \mathbb{R}^{n_p}\) and returning a vector in \(\mathbb{R}^{n_r}\).

The problem is solve using an iterative algorithm based on the Gauss-Newton method. At each iteration, an update \(\Delta \mathbf{p}\) to the current parameters \(\mathbf{p_k}\) is searched to minimize the cost function.

The solution is given by:

\[\Delta \mathbf{p} = - \left(\mathbf{J}^T \mathbf{J}\right)^{-1} \mathbf{J}^T \mathbf{r}\]

where \(\mathbf{r}\) is the full residual vector in \(\mathbb{R}^{n_r}\) evaluated at \(\mathbf{p_k}\) and \(\mathbf{J}\) is the full jacobian matrix in \(\mathbb{M}_{n_r, n_p}(\mathbb{R})\) containing each \(\frac{\partial r_j}{\partial p_l} \forall j \in ( 1, n_r ) \forall l \in ( 1, n_p )\).

The next iteration is performed for \(\mathbf{p_{k+1}} = \mathbf{p_k} + \Delta \mathbf{p}\) until convergence.

See also

The class pysolvegn.Term to represent a least square problem.

Using rJ-type term, this class store two Callable to compute the residual vector \(\mathbf{r}\) (as a 1D-array with shape (n_residuals,)) and jacobian matrix \(\mathbf{J}\) (as a 2D-array with shape (n_residuals, n_parameters)) from a set of parameters \(\mathbf{p}\) (as a 1D-array with shape (n_parameters,)).

Using gH-type term, this class store two Callable to compute the Hessian matrix \(\mathbf{H} = \mathbf{J}^T \mathbf{J}\) (as a 2D-array with shape (n_parameters, n_parameters)) and the gradient vector \(\mathbf{g} = \mathbf{J}^T \mathbf{r}\) (as a 1D-array with shape (n_parameters,)) from a set of parameters \(\mathbf{p}\) (as a 1D-array with shape (n_parameters,)).

Demonstration#

Consider a least squares problem of the form:

\[\min_{\mathbf{p}} = \frac{1}{2} \left(\| \mathbf{r}(\mathbf{p}) \|^2\right)\]

Developing the residuals \(\mathbf{r}(\mathbf{p})\) around the current parameters \(\mathbf{p_k}\):

\[\begin{split}\mathbf{r}(\mathbf{p_k} + \Delta \mathbf{p}) \approx \mathbf{r} + \mathbf{J} \Delta \mathbf{p} + \frac{1}{2} \begin{bmatrix} \Delta \mathbf{p}^T \mathbf{H}_1 \Delta \mathbf{p} \\ \vdots \\ \Delta \mathbf{p}^T \mathbf{H}_{n_r} \Delta \mathbf{p} \end{bmatrix} + \ldots\end{split}\]

where \(\mathbf{J}(\mathbf{p_k}) = \nabla \mathbf{r}(\mathbf{p_k})\) is the Jacobian of the residuals with respect to the parameters, and \(\mathbf{H}_j(\mathbf{p_k})\) is the Hessian of the \(j\)-th residual with respect to the parameters. By convention, the quantities are considered evaluated at \(\mathbf{p_k}\) such that \(\mathbf{r} = \mathbf{r}(\mathbf{p_k})\).

Therefore, for the least squares cost

\[F(\mathbf{p}) = \frac{1}{2} \| \mathbf{r}(\mathbf{p}) \|^2\]

Using the Taylor expansion above and retaining terms up to second order in \(\Delta \mathbf{p}\):

\[F(\mathbf{p_k} + \Delta \mathbf{p}) \approx F(\mathbf{p_k}) + \mathbf{J}^T \mathbf{r} \, \Delta \mathbf{p} + \frac{1}{2} \Delta \mathbf{p}^T \left( \mathbf{J}^T \mathbf{J} + \sum_{j=1}^{n_r} r_j \mathbf{H}_j \right) \Delta \mathbf{p}\]

The gradient of the least squares cost is therefore

\[\mathbf{g} = \nabla F(\mathbf{p_k}) = \mathbf{J}^T \mathbf{r}\]

and its exact Hessian is

\[\mathbf{H} = \mathbf{J}^T \mathbf{J} + \sum_{j=1}^{n_r} r_j \mathbf{H}_j\]

The Gauss-Newton approximation consists in neglecting the second term of the Hessian, giving

\[\mathbf{H}_{GN} = \mathbf{J}^T \mathbf{J}\]

The Gauss-Newton step is then obtained by solving

\[\mathbf{H}_{GN} \Delta \mathbf{p} = -\mathbf{g}.\]

When \(\mathbf{J}^T \mathbf{J}\) is invertible, this can formally be written as

\[\Delta \mathbf{p} = -(\mathbf{J}^T \mathbf{J})^{-1}\mathbf{J}^T\mathbf{r}.\]

Robust least squares optimization by the Gauss-Newton Method#

Robust cost functions \(\rho : \mathbb{R} \rightarrow \mathbb{R}\) can be used to reduce the influence of outliers. In that case, the standard least squares cost is replaced by a robust cost function that reduces the contribution of residuals with large errors.

Consider a robust least squares problem of the form:

\[\min_{\mathbf{p}} \frac{1}{2} \sum_{j \in ( 1, n_r )} \rho \left(\| \mathbf{r}_j(\mathbf{p}) \|^2\right)\]

where \(\mathbf{r}_j(\mathbf{p})\) is the \(j\)-th residual function (\(\mathbb{R}^{n_p} \rightarrow \mathbb{R}\)) depending on the parameters \(\mathbf{p} \in \mathbb{R}^{n_p}\).

The update \(\Delta \mathbf{p}\) to the current parameters \(\mathbf{p_k}\) is searched to minimize the cost function and the solution is given by:

\[\Delta \mathbf{p} = - \left(\tilde{\mathbf{J}}^T \tilde{\mathbf{J}}\right)^{-1} \tilde{\mathbf{J}}^T \tilde{\mathbf{r}}\]

Where :

\[\tilde{\mathbf{J}} = \sqrt{W_J} \mathbf{J} \quad \tilde{\mathbf{r}} = \frac{W_R}{\sqrt{W_J}} \mathbf{r}\]

The \(W\) factors are given by the following equations evaluated at \(\mathbf{p_k}\):

\[W_J = \text{diag}\left(\rho'(|\mathbf{r}_j|^2) + 2 \rho''(|\mathbf{r}_j|^2) |\mathbf{r}_j|^2\right)\]
\[W_R = \text{diag}\left(\rho'(|\mathbf{r}_j|^2)\right)\]

See also

The class pysolvegn.Term to represent a least square problem.

In addition to the Callable to compute the operators, this class stores the robust cost function to use for the optimization problem. This function returns the values of \(\rho\), \(\rho^{(1)}\) and \(\rho^{(2)}\) (as a three 1D-array with shape (n_residuals,)) from the squared of the residual vector \(\|\mathbf{r}\|^2\) (as a 1D-array with shape (n_residuals,)).

Demonstration#

Consider a robust least squares problem of the form:

\[\min_{\mathbf{p}} \frac{1}{2} \sum_{j \in ( 1, n_r )} \rho \left(\| \mathbf{r}_j(\mathbf{p}) \|^2\right)\]

where \(\mathbf{r}_j(\mathbf{p})\) is the \(j\)-th scalar residual and \(\rho\) is the robust cost function.

Developing the residuals \(\mathbf{r}_j(\mathbf{p})\) around the current parameters \(\mathbf{p_k}\) gives:

\[\mathbf{r}_j(\mathbf{p_k} + \Delta \mathbf{p}) \approx \mathbf{r}_j + \mathbf{J}_j \Delta \mathbf{p} + \frac{1}{2} \Delta \mathbf{p}^T \mathbf{H}_j \Delta \mathbf{p} + \ldots\]

where \(\mathbf{J}_j(\mathbf{p_k}) = \nabla \mathbf{r}_j(\mathbf{p_k})\) is the Jacobian of the \(j\)-th residual with respect to the parameters, and \(\mathbf{H}_j(\mathbf{p_k})\) is its Hessian. By convention, all quantities are considered evaluated at \(\mathbf{p_k}\), such that \(\mathbf{r}_j = \mathbf{r}_j(\mathbf{p_k})\).

Let \(Z_j = \| \mathbf{r}_j \|^2\) be the squared residual at the current parameters. The robust cost function can then be developed around \(Z_j\):

\[\rho(Z_j + \delta Z_j) \approx \rho(Z_j) + \rho'(Z_j)\delta Z_j + \frac{1}{2} \rho''(Z_j) \delta Z_j^2 + \ldots\]

where \(\delta Z_j\) is the change in the squared residual resulting from the parameter update:

\[\delta Z_j = \| \mathbf{r}_j(\mathbf{p_k} + \Delta \mathbf{p}) \|^2 - \| \mathbf{r}_j(\mathbf{p_k}) \|^2\]

Using the Taylor expansion of the residual and retaining terms up to second order in \(\Delta \mathbf{p}\):

\[\delta Z_j \approx 2 \mathbf{r}_j^T \mathbf{J}_j \Delta \mathbf{p} + \Delta \mathbf{p}^T \left( \mathbf{J}_j^T \mathbf{J}_j + \mathbf{r}_j^T \mathbf{H}_j \right) \Delta \mathbf{p} + \ldots\]

In a similar way, the squared term \(\delta Z_j^2\) can be approximated as:

\[\delta Z_j^2 \approx 4 \left( \mathbf{r}_j^T \mathbf{J}_j \Delta \mathbf{p} \right)^2 + \ldots\]

Substituting these expressions into the Taylor expansion of the robust cost function gives:

\[\rho(Z_j + \delta Z_j) \approx \rho(Z_j) + \rho'(Z_j) \Big[ \Delta \mathbf{p}^T \left( \mathbf{J}_j^T \mathbf{J}_j + \mathbf{r}_j^T \mathbf{H}_j \right) \Delta \mathbf{p} + 2 \mathbf{r}_j^T \mathbf{J}_j \Delta \mathbf{p} \Big] + 2 \rho''(Z_j) \left( \mathbf{r}_j^T \mathbf{J}_j \Delta \mathbf{p} \right)^2 + \ldots\]

By summing over all residuals, the gradient and the Hessian of the robust cost with respect to the parameters is therefore:

\[\mathbf{g} \approx \sum_j 2 \rho'(Z_j) \mathbf{J}_j^T \mathbf{r}_j\]
\[\mathbf{H} \approx \sum_j \Big[2 \rho'(Z_j) \left( \mathbf{J}_j^T \mathbf{J}_j + \mathbf{r}_j^T \mathbf{H}_j \right) + 4 \rho''(Z_j) \mathbf{J}_j^T \mathbf{r}_j \mathbf{r}_j^T \mathbf{J}_j \Big]\]

The Gauss-Newton approximation consists in neglecting the second-order derivatives of the residuals. The term involving \(r_j \mathbf{H}_j\) is neglected.

\[\mathbf{H} \approx \sum_j \Big[2 \rho'(Z_j) \mathbf{J}_j^T \mathbf{J}_j + 4 \rho''(Z_j) \mathbf{J}_j^T \mathbf{r}_j \mathbf{r}_j^T \mathbf{J}_j \Big]\]
\[\mathbf{H} \approx \sum_j 2 \mathbf{J}_j^T \Big[ \rho'(Z_j) + 2 \rho''(Z_j) Z_j \Big] \mathbf{J}_j\]

Finally, defining a diagonal matrix \(W_J\) and a vector \(W_R\), the Hessian and gradient approximation can be written as:

\[\mathbf{H} = \mathbf{J}^T \sqrt{W_J}^T \sqrt{W_J} \mathbf{J} \quad \mathbf{g} = W_R \mathbf{J}^T \mathbf{r}\]

where:

\[W_J = \text{diag}\left(\rho'(|\mathbf{r}_j|^2) + 2 \rho''(|\mathbf{r}_j|^2) |\mathbf{r}_j|^2\right)\]
\[W_R = \text{diag}\left(\rho'(|\mathbf{r}_j|^2)\right)\]

This system can be expressed as a standard least squares system by introducing a modified Jacobian and a modified residual:

\[\tilde{\mathbf{J}} = \sqrt{W_J}\mathbf{J} \quad \tilde{\mathbf{r}} = W_J^{-1/2} W_R \mathbf{r}.\]

Such that:

\[\tilde{\mathbf{J}}^T \tilde{\mathbf{J}} \Delta \mathbf{p} = -\tilde{\mathbf{J}}^T \tilde{\mathbf{r}}.\]

Adding regularization to the Gauss-Newton update#

In many optimization problems, the objective function is composed of several least squares terms. The first term usually corresponds to the data fitting problem, while the remaining terms can be used to regularize the solution.

The resulting objective function can be written as:

\[\min_{\mathbf{p}} \frac{1}{2} \sum_{i} w_i \sum_{j} \rho_i \left( \| \mathbf{r}_{i,j}(\mathbf{p}) \|^2 \right)\]

where \(i\) indexes the different least squares terms and \(j\) indexes the residuals within each term.

The scalar \(w_i\) is the weight associated with the \(i\)-th term, and \(\rho_i\) is its robust cost function. Each term can therefore have its own residuals, weight, and robust cost function.

By convention, the first term (\(i=0\)) is the main least squares term, which usually contains the data residuals. The remaining terms (\(i \geq 1\)) are considered regularization terms.

Note

A regularization term can be used to introduce additional constraints or prior information into the optimization problem. Its weight \(w_i\) controls its influence relative to the other terms.

For each term, the robust Gauss-Newton approximation described above provides a modified residual \(\tilde{\mathbf{r}}_i\) and a modified Jacobian \(\tilde{\mathbf{J}}_i\).

Since the objective function is the sum of all the terms, their contributions to the gradient and Hessian approximation can be summed directly. The global Gauss-Newton system is therefore:

\[\left( \sum_i w_i \tilde{\mathbf{J}}_i^T \tilde{\mathbf{J}}_i \right) \Delta \mathbf{p} = - \sum_i w_i \tilde{\mathbf{J}}_i^T \tilde{\mathbf{r}}_i.\]

See also

The class pysolvegn.Term to represent a term in a least square problem.

In addition to the Callable to compute the operators, this class stores the weight associated to the term.

Changing the parametrization#

Consider a least squares problem of the form:

\[\min_{\mathbf{p}_{\mathrm{out}}} \frac{1}{2} \sum_i w_i \sum_j \rho_i \left( \| \mathbf{r}_{i,j}(\mathbf{p}_{\mathrm{out}}) \|^2 \right)\]

In some applications, it is convenient to optimize the problem using a different set of parameters than those expected by the residual functions. This can be achieved by introducing a parametrization that maps the input parameters \(\mathbf{p}_{\mathrm{in}}\) to the output parameters \(\mathbf{p}_{\mathrm{out}}\):

\[\mathbf{p}_{\mathrm{out}} = P(\mathbf{p}_{\mathrm{in}})\]

where \(\mathbf{p}_{\mathrm{in}} \in \mathbb{R}^{n_{p_{\mathrm{in}}}}\) are the parameters optimized by the Gauss-Newton algorithm, while \(\mathbf{p}_{\mathrm{out}} \in \mathbb{R}^{n_{p_{\mathrm{out}}}}\) are the parameters passed to the residual functions.

The optimization problem can therefore be rewritten directly in terms of the input parameters:

\[\min_{\mathbf{p}_{\mathrm{in}}} \frac{1}{2} \sum_i w_i \sum_j \rho_i \left( \left\| \mathbf{r}_{i,j} \left( P(\mathbf{p}_{\mathrm{in}}) \right) \right\|^2 \right)\]

At each iteration, the Gauss-Newton algorithm searches for an update \(\Delta\mathbf{p}_{\mathrm{in}}\) in the space of input parameters. The corresponding output parameters are obtained through the parametrization:

\[\mathbf{p}_{\mathrm{out}} = P(\mathbf{p}_{\mathrm{in}}).\]

To compute the Jacobian of the residuals with respect to the parameters being optimized, we introduce the Jacobian of the parametrization:

\[\mathbf{J}_P = \frac{\partial \mathbf{p}_{\mathrm{out}}} {\partial \mathbf{p}_{\mathrm{in}}}\]

Using the chain rule, the Jacobian of the \(j\)-th residual of the \(i\)-th term with respect to the input parameters is:

\[ \begin{align}\begin{aligned}\mathbf{J}_{i,j,\mathrm{in}} = \frac{\partial \mathbf{r}_{i,j}} {\partial \mathbf{p}_{\mathrm{in}}} = \frac{\partial \mathbf{r}_{i,j}} {\partial \mathbf{p}_{\mathrm{out}}} \frac{\partial \mathbf{p}_{\mathrm{out}}} {\partial \mathbf{p}_{\mathrm{in}}}\\= \mathbf{J}_{i,j} \mathbf{J}_P\end{aligned}\end{align} \]

Therefore, the parametrization only modifies the Jacobian used by the Gauss-Newton algorithm. The robust weighting described in the previous section is applied in exactly the same way, giving:

\[\tilde{\mathbf{J}}_i = \sqrt{W_{J,i}} \mathbf{J}_i \mathbf{J}_P\]

while the modified residual remains:

\[\tilde{\mathbf{r}}_i = W_{J,i}^{-1/2} W_{R,i} \mathbf{r}_i\]

The Gauss-Newton system is consequently solved in the input parameter space:

\[\left( \sum_i w_i \tilde{\mathbf{J}}_i^T \tilde{\mathbf{J}}_i \right) \Delta\mathbf{p}_{\mathrm{in}} = - \sum_i w_i \tilde{\mathbf{J}}_i^T \tilde{\mathbf{r}}_i\]

The important point is that \(\Delta\mathbf{p}_{\mathrm{in}}\) has the dimension of the input parameter space. The parametrization is therefore accounted for through \(\mathbf{J}_P\) when computing the Jacobians.

Once the Gauss-Newton system has been solved, the input parameters are updated as:

\[\mathbf{p}_{\mathrm{in}}^{k+1} = \mathbf{p}_{\mathrm{in}}^k + \Delta\mathbf{p}_{\mathrm{in}}\]

The corresponding output parameters are then obtained by applying the parametrization:

\[\mathbf{p}_{\mathrm{out}}^{k+1} = P \left( \mathbf{p}_{\mathrm{in}}^{k+1} \right)\]

This formulation separates the parameters used by the optimization algorithm from those used by the residual functions. The Gauss-Newton algorithm operates entirely in the input parameter space, while the parametrization maps these parameters to the output space required by the optimization terms.

See also

The class pysolvegn.Parametrization represents a parameter transformation by storing the functions required to compute the output parameters and the Jacobian of the transformation.

Given the input parameters \(\mathbf{p}_{\mathrm{in}}\) as a 1D-array with shape (n_parameters,), the parametrization computes the output parameters \(\mathbf{p}_{\mathrm{out}}\) as a 1D-array with shape (n_p_outputs,) and the Jacobian \(\mathbf{J}_P\) as a 2D-array with shape (n_p_outputs, n_parameters)
